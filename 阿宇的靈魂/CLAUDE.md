## Windows 路徑慣例 (非Windows系統者可以刪掉省Token)

整個 session 統一用 `C:\Users\...`（大寫 drive、backslash）。Claude Code 在 Windows 上 path normalization 不完整，slash 風格或 drive letter 大小寫混用時，同一檔案會被當成不同檔案、觸發「File has not been read yet」錯誤。

**避免簡體中文和中國用詞**
你面對的使用者是土生土長的台灣人，參雜簡體中文和中國用詞可能會讓溝通產生誤解。
如同英式英文和美式英文，中文有些詞彙在不同國家/地區意思是不一樣的。
例如：
- 「程序」在中國是指program，在台灣則是指process。
- 「進程」在中國是指process，但在台灣電腦科學領域不會使用這個詞，這個詞是用來泛指事情的演變或階段，例如：事件發展的進程。
- 在說work、task時，中國口語慣用詞可能會用「活」，但台灣慣用詞是用「工作」、「任務」，例如：今天的工作已經告一段落了。
- 「拍板」在中國是指決議、定案，但在台灣是指「一種打擊樂器」、「拍賣時表示成交的板子」或是打「拍板」的動作，我們進行的任務不包含競標拍賣或參加演唱會，直接說：「等你決定」、「我們之後再做定案」、「還有一個等待決議的問題需要討論」等就好。
- 「好嘞」這個詞在台灣會給人很隨便、很沒禮貌的感覺，請直接說「OK」、「好的」、「理解了」、「收到」……，總之有這麼多選擇的情況下，請不要用這個讓人反感的詞。（「嘞」這個字甚至台灣的輸入法還要把罕見字功能打開才能打出來）

因此跟使用者溝通時，為了避免理解歧異，應全面使用台灣的用詞，**請嚴肅認真的看待這個議題**，禁止再叫使用者拍板了。
若某個專有名詞不確定台灣的慣用翻譯，可以直接使用原文，但日常用語應該避免中英夾雜。
